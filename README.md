# Tuboy's Lopez — Café Website Demo

A polished, responsive one-page concept website for Tuboy's Lopez in Lopez,
Quezon. The demo uses beginner-friendly HTML, CSS, and vanilla JavaScript with
no build step.

## Preview locally

From this folder, start a local web server:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in a browser.

## Project files

- `index.html` — page content and structure
- `styles.css` — responsive layout, color palette, and animation styles
- `script.js` — mobile navigation, menu filtering, and reveal effects

> **Note:** Menu pricing, opening hours, phone number, and social links are
> placeholders for client presentation and should be replaced before launch.
